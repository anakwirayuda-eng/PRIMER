## Dasar keputusan

- Perubahan persistensi mengikuti transisi engine yang benar-benar terjadi dan kontrak save proyek. Pengujian memakai `advance`, `serialize`, dan `deserialize` asli, lalu membandingkan keadaan yang dipulihkan; bukan hanya memeriksa apakah fungsi simpan dipanggil.
- Pola modal mengikuti [W3C APG: Dialog (Modal)](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/): navigasi Tab berada di dalam dialog dan fokus dikembalikan ke pemicu saat ditutup. Peran kontrol lipatan mengacu pada [MDN: summary](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/summary). Perilaku diperiksa lagi dengan keyboard Chromium pada Jejak Perawatan.
- Penantian log memakai Promise dari operasi [Node.js `fsPromises.appendFile`](https://nodejs.org/api/fs.html#fspromisesappendfilepath-data-options). Uji main process menahan append secara sengaja, kemudian memeriksa hasil baca file sebenarnya di direktori sementara.
- `RESPONS_PENERIMAAN` dan `PILIH_INGATKAN` tidak ditambahkan ke daftar autosave: penyelesaian kunjungannya sudah menghasilkan event autosave. Pilihan diagnosis klinik belum langsung memberikan penilaian benar/salah seperti langkah IGD, sehingga tidak disamakan begitu saja dengan kasus tersebut.

Aturan penilaian, angka klinis, peluang kader, dan konten simulasi tidak diubah. Perbandingan SHA-256 atas **227 file engine, konten, dan aset** dengan sumber asli menghasilkan **0 perbedaan**. Repo sumber `D:\Dev\PRIMER-CODEX-lab` tetap bersih pada commit `6e9f17c15465d50e19b95a2dc7a0d1374275471d`.
